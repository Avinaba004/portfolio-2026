# Avinaba Ghosh — Portfolio

An interactive engineering portfolio built with Next.js 16, React 19, TypeScript, Tailwind CSS v4, Motion, React Three Fiber and Lenis.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build && npm start
```

## Content

All facts live in `src/data/` (`profile.ts`, `projects.ts`, `system.ts`). The downloadable resume is `public/resume/Avinaba_Ghosh_Resume.pdf`.

## Deploy

Import the repo in Vercel — no configuration required. For a custom domain, set `NEXT_PUBLIC_SITE_URL`.
